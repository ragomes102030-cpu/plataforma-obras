# Skill — Visualização de Planejamento
Modo: independente

## Objetivo
Escolher a representação adequada para cada informação de engenharia.

## Representações
- árvore EAP;
- tabela/dicionário;
- Gantt;
- caminho crítico;
- curva S;
- físico-financeiro;
- planejado × realizado;
- matriz de riscos;
- mapa de restrições;
- dashboard executivo;
- visão do engenheiro;
- visão de campo;
- visão do cliente.

## Regra
Visualização não cria dados. Deve refletir exclusivamente dados validados e indicar ausência de informação relevante.

# Skill: Pacote de trabalho

Um pacote de trabalho é o nível da EAP no qual o escopo pode ser estimado, atribuído, programado, medido e controlado de forma prática.

## Indicadores de prontidão

Uma folha deve, quando aplicável, possuir:
- unidade;
- quantidade planejada;
- localização;
- responsável;
- descrição;
- inclusões;
- exclusões;
- critério de aceitação.

A ausência de algum campo não torna automaticamente a EAP inválida: Arquimedes deve distinguir informação ainda desconhecida de erro estrutural.

## Regra

Não transformar automaticamente toda folha em atividade. A conversão para atividade pertence à camada de planejamento executivo.

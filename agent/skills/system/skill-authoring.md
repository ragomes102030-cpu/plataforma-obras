# Skill: skill-authoring

## Objetivo
Criar e manter skills pequenas, verificáveis e relevantes ao domínio da Plataforma Obras.

## Quando usar
Quando o agente precisar de uma capacidade reutilizável ainda não coberta ou revisar o catálogo de skills.

## Regras
Cada skill deve definir objetivo, gatilhos, entradas, procedimento, saída, critérios de parada, limites e teste. Skills não são ferramentas, não concedem permissões e não substituem validadores. Evitar skills duplicadas, vagas, com instruções contraditórias ou sem teste. Preferir carregar poucas skills relevantes por execução.

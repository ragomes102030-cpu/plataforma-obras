# Skill: grill-me

## Objetivo
Submeter premissas de uma proposta a perguntas críticas antes de decisões caras ou difíceis de reverter.

## Quando usar
Definição de escopo, arquitetura, seleção de tecnologia, aprovação de EAP/baseline e decisões com lacunas materiais.

## Procedimento
1. Listar hipóteses que mudam o resultado.
2. Ordenar por impacto e irreversibilidade.
3. Perguntar uma coisa por vez, somente quando a resposta for necessária para avançar com segurança.
4. Se for possível produzir uma proposta segura, avançar com pressupostos declarados e itens pendentes em vez de bloquear com questionário.
5. Parar quando as decisões restantes não alterarem materialmente o próximo passo.

## Limites
Não transformar a conversa em interrogatório. Nunca tratar silêncio como aprovação nem inferir consentimento para mutações.
